# KEI Estate Investment Website

A modern, responsive, and secure business website developed for **KEI Estate Investment** using **HTML5, CSS3, JavaScript, PHP, Bootstrap 5, PHPMailer, and Google reCAPTCHA**. The project provides a professional online presence for the company while allowing visitors to explore services, discover tourist attractions in Sierra Leone, and securely contact the business.

---

# 📖 Description

This project demonstrates the development of a full-stack business website combining modern frontend technologies with secure backend processing. The application emphasizes responsive web design, user experience, website security, and production deployment.

The website includes a responsive landing page, service showcase, tourism gallery, contact form, social media integration, and multiple anti-spam security mechanisms.

# 🛠 Tech Stack Used and Learned

### Frontend

* **HTML5** – Semantic markup for accessibility, maintainability, and SEO.
* **CSS3** – Flexbox, Grid, animations, transitions, and media queries for responsive layouts.
* **Bootstrap 5** – Responsive components, navigation bar, carousel, cards, utilities, and mobile-first design.
* **Bootstrap Icons & Font Awesome** – Professional icons and social media integration.
* **JavaScript (ES6)** – Form validation, DOM manipulation, animations, Fetch API, and dynamic content loading.

### Backend

* **PHP** – Secure server-side form processing.
* **Composer** – Dependency management.
* **PHPMailer** – SMTP email delivery.
* **PHP Dotenv (.env)** – Secure environment variable management.

### APIs & Services

* **Google reCAPTCHA** – Protection against automated bot submissions.
* **SMTP (Gmail)** – Secure email communication.

### Deployment

* **Namecheap Shared Hosting** – Live website deployment.
* **SSL Certificate (HTTPS)** – Secure encrypted communication.

### Version Control

* **Git & GitHub** – Source code management and version control.

# 🔐 Security Features

* Google reCAPTCHA server-side verification
* Honeypot field protection against automated bots
* Regex filtering for malicious URLs and JavaScript injection
* Blacklisted phishing and spam keyword detection
* Disposable email detection
* IP-based rate limiting to prevent submission flooding
* Bot-generated name detection using Regular Expressions
* Secure environment variables for sensitive credentials
* Activity logging for suspicious requests and spam attempts

# 🚀 Installation

```bash

```

Install Composer dependencies:

```bash

```

Create a `.env` file and configure:

* SMTP credentials
* Google reCAPTCHA Secret Key
* Social media URLs

Run the project using:

* XAMPP
* Laragon
* WAMP
* PHP Built-in Server
